# 🌍 세계 여행 지도 (World Travel Map)

> **쿠사리님의 발길이 닿은 전 세계 195개국을 기록하는 인터랙티브 세계 여행 아카이브**
> D3.js 기반의 Natural Earth 벡터 세계 지도 위에 다녀온 나라를 색칠하고, 대표 도시 및 랜드마크 체크리스트, 여행 메모를 관리하는 모던 웹앱입니다.

---

## ✨ 핵심 기능

1. **전 세계 195개국 벡터 지도 렌더링**
   - 왜곡이 적고 아름다운 Natural Earth 투영법 적용
   - 마우스 휠 & 버튼 자유로운 줌/팬 탐색
2. **3단계 맞춤형 방문 등급**
   - 🟢 방문 완료 (Visited)
   - ✈️ 체류·거주 (Living/Staying)
   - 🌟 버킷리스트 (Bucket List)
   - ⬜ 미방문 (Unvisited)
3. **국가별 대표 도시 & 랜드마크 큐레이션**
   - 전 세계 주요 국가별 4~7개 필수 명소 체크리스트 내장
   - 원클릭 🗺️ 구글 지도 검색 직결
   - 사용자 나만의 도시·명소 자유 추가 지원
4. **스마트 편의 기능**
   - 🎲 어디 갈까? 미방문 국가 랜덤 추천 줌인
   - 🏷️ 국명 라벨 표시 온/오프 토글
   - 실시간 다국어(한국어/영어), 수도, 명소 검색
   - 6대륙 필터 (아시아, 유럽, 북미, 남미, 아프리카, 오세아니아)
5. **데이터 영구 보존 & 내보내기**
   - 브라우저 로컬스토리지 실시간 자동저장
   - 1920x1080 고화질 PNG 지도 이미지 다운로드
   - JSON 백업 파일 내보내기 및 복원
